NS2 Pro — 无线连接 Switch 2 Pro Controller 到 PC

适用：Intel / AMD 64 位 Windows 10 2004（19041）及以上、Windows 11。
电脑需要支持蓝牙 LE 中央角色的适配器。暂不支持 ARM64 和 32 位系统。

安装包已包含 .NET、Windows App SDK 和官方 ViGEmBus 1.22.0 驱动，无需联网查找这些组件。
缺少手柄驱动时会自动安装，因此安装程序需要管理员权限；已安装驱动时跳过安装。
日常运行 NS2 Pro 不需要管理员权限。驱动安装可能要求重启，安装程序会明确提示。

首次连接：
1. 启动 NS2 Pro，按连接指南检查蓝牙与驱动。
2. 拔掉手柄 USB，点击开始连接。
3. 长按手柄顶部 SYNC，直到指示灯循环闪烁。
4. 按键或转动摇杆，确认收到真实输入。

无需在 Windows 蓝牙设置中手动配对。连接 PC 使用 SYNC；HOME 会唤醒 NS2。
结束后在应用里断开 PC 连接，再按 HOME 回到 NS2，无需重新配对。

当前支持按键、摇杆与电量；震动、陀螺仪和耳机音频暂未接入。
关闭窗口默认缩到托盘；需要完全退出时，点击应用左下角的「退出应用」。
卸载 NS2 Pro 不会删除用户设置，也不会移除其他软件可能共用的 ViGEmBus 驱动。
