NS2Pro手柄PC连接器 — 无线连接 Switch 2 Pro Controller 到 PC

适用：Intel / AMD 64 位 Windows 10 2004（19041）及以上、Windows 11。
电脑需要支持蓝牙 LE 中央角色的适配器。暂不支持 ARM64 和 32 位系统。

安装包已包含 .NET、Windows App SDK 和官方 ViGEmBus 1.22.0 驱动，无需联网查找这些组件。
缺少手柄驱动时会自动安装，并请求管理员权限；已安装驱动时跳过安装。仅当前用户安装时，应用本身无需提权。
日常运行 NS2Pro手柄PC连接器不需要管理员权限。驱动安装可能要求重启，安装程序会明确提示。

首次连接：
1. 启动 NS2Pro手柄PC连接器，按连接指南检查蓝牙与驱动。
2. 拔掉手柄 USB，点击开始连接。
3. 长按手柄顶部充电口旁的 SYNC 小键，直到指示灯循环闪烁。
4. 按键或转动摇杆，确认收到真实输入。

无需在 Windows 蓝牙设置中手动配对。连接 PC 使用 SYNC；连接成功后指示灯持续闪烁属于正常现象。
结束后在应用里断开 PC 连接，再按 HOME 回到 NS2，无需重新配对。

当前支持按键、摇杆、电量、充电状态和通用游戏震动；陀螺仪和耳机音频暂未接入。
原生触觉增强为可选实验功能，在游戏模式中按需安装组件并自动管理；具体游戏的震感是否提升需实际体验。
启动后会检查 GitHub 正式版更新，有新版时提供 Release 下载入口。已有安装会沿用原位置更新，并保留用户设置。
关闭窗口默认断开连接并退出；最小化可保持连接。也可在设置中开启关闭窗口后继续在后台运行，再从托盘菜单完全退出。
卸载 NS2Pro手柄PC连接器不会删除用户设置，也不会移除其他软件可能共用的 ViGEmBus 驱动。
