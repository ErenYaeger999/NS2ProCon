# DualSense 六轴体感

v0.9.0 起提供，仅用于「原生触觉增强（实验）」。本机已确认三轴读取、静置校准、按键／摇杆／震动共存正常；实际游戏体感瞄准需按游戏确认。

## 使用

1. 断开 PC 连接，在「设置与诊断」选择「原生触觉增强」。已有增强环境可直接复用。
2. 保持「体感输入 → 向 DualSense 提供六轴体感」开启，再连接手柄。
3. 到「手柄测试 → 体感测试」转动手柄，确认三轴指示有响应。
4. 点击「校准体感」，将手柄静置在桌面上约 2 秒。期间暂停震动；有晃动会重新等待静止。校准保存在电脑端，重新连接同一只手柄可复用。
5. 启动支持六轴体感的 PC 游戏，在游戏中开启体感瞄准；也可在 Steam 的控制器布局中设置体感。灵敏度和启用键在游戏／Steam 中调整。

连接器提供角速度与加速度，不生成鼠标或摇杆瞄准。普通 Xbox 模式不提供六轴。修改体感开关需要先断开，下一次增强连接生效。

三轴指示展示转动速度，静置时应接近零；不是绝对朝向。加速度包含重力，放稳时大小通常约 1 g。采样率统计真实有效的体感通知，不是虚拟报告发送次数，也不代表端到端延迟。

体感使用公共输入通道时，电量和充电状态约每 30 秒刷新一次，刚插拔充电线时图标可能稍后更新。

## 游戏兼容性

- PC 版支持 DualSense 震动，不代表它同时支持陀螺仪。没有原生支持时，需在 Steam 中设置体感。
- Steam Input 可能将控制器转换为其他输入，影响游戏原生 DualSense 触觉。原生体感与原生触觉能否同时工作，需逐游戏验证。
- 连接器不改变游戏的按键图标策略；若游戏支持，可在游戏内选择 Xbox／ABXY 图标。
- 修改游戏的输入方式后，必要时重新启动游戏。

体感通道不可用时，按键和震动仍可使用。先检查测试页的提示，再断开重连；日志和诊断信息会记录通道初始化及实际采样情况。

## 实现与验证边界

读取 BLE FD2 公共报告。支持并行时保留 Pro 按键通知；无法并行时，按键与六轴统一使用 FD2，电量和充电位通过短暂订阅原 Pro 通知定期刷新，期间使用原报告保持按键输入；不根据电压猜测百分比。初始化必须收到有效六轴首帧才算成功；失败时恢复原按键通道。

新增写入限定为瞬时输入特征配置、公共报告选择和启动；结束时恢复默认报告。软件不写主机配对、Flash 或固件。

仅保留最新体感状态。角速度在 120 ms 内没有新有效数据时归零，静态加速度保留最后已知值；断开、休眠及新连接清除旧状态。校准只修正静止零偏，不在瞄准过程中自动改零点。

自动检查覆盖报告边界、轴方向、单位转换、规范 V5 字段、序号循环、重复／过期数据、静置与移动校准、保存恢复，以及实际 TCP 写入器与现有触觉反馈共存。测试页通过真实 WinUI 构建与交互检查。本机用户已确认真实手柄三轴、校准和原有输入／震动正常。额外只读检查确认虚拟 DualSense 的六轴字段持续变化、时间戳递增、特征报告的单位为 16 counts/(°/s) 与 8192 counts/g。尚未据此宣称特定游戏的体感瞄准已验收。
