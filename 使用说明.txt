NS2Pro手柄PC连接器

推荐从 GitHub Release 下载并安装：
https://github.com/ErenYaeger999/NS2ProCon/releases/latest

1. 打开应用，首次进入按连接指南检查环境。
2. 拔掉 USB，点击连接手柄，再长按顶部 SYNC，直到指示灯循环闪烁。
3. 连接成功后即可开始游戏，或到手柄测试页查看按键与双摇杆。
4. 回到 NS2：先断开 PC，再按 HOME，无需重新配对。

连接 PC 时请勿按 HOME，它会唤醒 NS2；连接后指示灯持续闪烁属于正常现象。
点叉默认断开并退出，最小化保持连接；可在设置中主动开启后台运行。

功能、系统要求、空间占用与致谢见 README.md。
Start-PC.cmd 和 tools 中的 Python 程序为开发诊断后备，需要自行准备 Python 依赖；
它们不包含在安装版中，也不要与原生应用同时连接手柄。
后备脚本默认发现处于 SYNC 的 Pro 手柄，可用 --address 指定蓝牙地址。
